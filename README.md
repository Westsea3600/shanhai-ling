# 山海拾灵 · 御灵行纪

**一款用纯 HTML5 + Canvas 写的山海经题材御灵动作 RPG —— 探索 · 捕捉 · 培育 · 讨伐**

全部美术（灵物 / 角色 / 地块 / 装备 / 图标 / 特效）由代码程序化生成，**零外部资源**，单机离线可玩。

## 快速开始

| 方式 | 步骤 |
| --- | --- |
| **在线游玩**（无需下载） | 直接打开公网地址：**https://shanhai-ling.surge.sh/** |
| **推荐**（有 Node.js） | 双击 `启动游戏.bat`，或命令行执行 `node server.js`，浏览器打开 http://127.0.0.1:8791/ |
| 最简单 | 直接双击 `index.html`（file:// 下部分浏览器禁用 localStorage，可在系统页用"导出/导入存档"） |

> 存档保存在浏览器 localStorage 里：在线版与本地版的存档互不相通，可在游戏内【系统】页用"导出/导入存档"搬运。部署信息见 `DEPLOY.md`。

建议 Chrome / Edge 最新版，窗口不小于 1000 × 620。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动 |
| **鼠标左键** / `空格` | 普通攻击（朝准星方向） |
| `1` ~ `4` | 职业技能（随等级解锁，冷却剩余秒数直接标在键位上） |
| **鼠标右键** | 点地移动（BFS 寻路，自动绕开水面与岩石） |
| `E` | 投掷缚灵索捕捉（自动锁定最近的虚弱野生灵物，**低档索优先消耗**） |
| `Q` / `R` | 喝血药 / 喝魔药（低档优先） |
| `F` | 与 NPC 对话 / 进入传送门 |
| `T` | 自动战斗开关（自动索敌、自动出手、自动追击） |
| `H` | 灵宠战术：进攻 / 防守 / 跟随 |
| `B` `P` `J` `C` `M` | 背包 / 灵宠 / 委托 / 角色 / 图鉴 |
| `Esc` / `Tab` | 无面板→系统菜单；有面板→关闭（有弹窗先关弹窗） |
| `F5` | 保存进度（已拦截浏览器刷新；捕捉 / 买卖 / 强化 / 进化也会自动落盘） |

## 核心玩法

### 1. 御灵捕捉（打残 → 掷索 → 三摇）
```text
捕获率 = 种族基数 × 索的倍率 × (1 − 当前血量比 × 0.75) × 等级修正 × 状态加成
单摇成功率 = 总捕获率^(1/3)，三摇全过才算结契
```
- 三档缚灵索：缚灵索（×1.0）→ 赤晶索（×1.75）→ 山海印（×2.7），E 键自动用**最便宜**的一档，好索留给稀有的灵物
- 带异常状态（减速 / 眩晕 / 灼烧…）的灵物更好捕捉；捕捉中目标头顶会出现眩晕星
- **守护者（BOSS）与唤魂不可捕捉**，图鉴凭击败收录

### 2. 培育与进化
- 出战灵物分享 60% 战斗经验；**并肩击杀**单独计数（个别种族的进化条件）
- 每只灵物捕捉时随机获得：**性格**（6 种，微调四维）+ **资质 0~15**
- 约 1/90 概率遇到 **✨闪光灵物**（属性 ×1.28、经验 ×3）
- 进化条件写在灵宠页与图鉴里（等级达标即进化；山膏 / 御凶还需并肩击杀 ≥15/20）
- 7 条进化线：狸力→山膏 · 旋龟→玄龟 · 鹿蜀→文马 · 火鼠→火浣兽 · 猼訑→风猼 · 九尾狐→涂山君 · 天狗→御凶

### 3. 属性克制与连携
```text
火 → 木 → 水 → 火        雷 → 风 → 土 → 雷
克制 ×1.5   被克制 ×0.67   同属性 ×0.8
```
| 连携 | 触发 | 效果 |
| --- | --- | --- |
| 爆燃 | 灼烧 + 风系命中 | 170% 范围爆发并刷新灼烧 |
| 过载 | 灼烧 + 雷系命中 | 190% + 眩晕 0.9s |
| 毒爆 | 滋毒 + 火系命中 | 150% + 向周围扩散滋毒 |
| 超导 | 麻痹 + 水系命中 | 160% 连锁跳 3 个敌人 |
| 潮陷 | 缓流 + 土系命中 | 180% + 眩晕 0.8s |

连携只有**玩家与灵宠**打出的命中才会触发（魔物命中不触发）。

### 4. 实时战斗
- 3 职业 × 4 技能：剑客（近身连斩）/ 术士（元素范围）/ 弓手（游走点杀）
- 灵宠独立 AI（进攻 / 防守 / 跟随三模式）：远程灵宠会保持距离，治疗 / 护盾技在残血时自动释放，濒死后脱战 10 秒自愈归队
- **BOSS 三阶段战**：血量 62% / 32% 进入狂暴——攻击提升、全屏震颤、脚下光环 + 环绕火星 + 阶段星标，三阶段召唤增援
- 地形规则：水面 / 岩浆挡行走不挡弹道；岩石 / 树木 / 墙体挡弹道

### 5. 世界（6 张地图 · 等级上限 30）
| 地图 | 等级 | 主题 | 守护者 |
| --- | --- | --- | --- |
| 落霞村 | 安全区 | 商店 / 铁匠 / 治疗 / 委托 | — |
| 青丘泽 | 2–7 | 草原水泽 | — |
| 若木林 | 6–12 | 密林 | 毕方（火） |
| 炎波火泽 | 11–17 | 岩浆焦土 | 狰（火） |
| 幽都山 | 15–21 | 暗光洞窟（火把照明） | 蛊雕（风） |
| 雷泽 | 20–26 | 雷暴沼泽 | 帝江（混沌·终焉） |

- **随机事件**：灵物迁徙（温顺灵物群 40s，结束自动散去）/ 兽潮涌动（全图魔物来袭）/ 行脚商队（卖灵玉档装备与稀有货，杂货铺买不到的都在这）
- BOSS 击败后按强度 2~4 分钟重生（右上角倒计时），首次击败掉落**唯一装备**（毕方羽翎 / 帝江之核，永不进入商店与掉落池，不可出售）

### 6. 装备与经济
- 6 部位 × 3 档（青铜 Lv1 / 玄铁 Lv10 / 灵玉 Lv20）+ 2 件唯一，共 26 件
- 铁匠铺：购买（按职业过滤武器）/ **强化 +1~+6**（玄铁 + 金币，每级 +8% 基础数值）/ 出售（唯一装备谢绝回收）
- 商队与铁匠购买、强化、买卖全部**即时落盘**

### 7. 委托与成就
- **主线 8 条**（m1 初试身手 → m8 混沌终焉），完成自动解锁下一条
- **支线 8 条**：讨伐 / 收集 / 捕捉 / 图鉴，散布在各图 NPC
- 成就 10 个（初次结契 / 图鉴 / 守护者 / 强化 +6 / 满级 / 富甲一方…）
- 击败**帝江**触发终章结算，之后世界继续开放（BOSS 会重生，图鉴继续收集）

## 项目结构

```text
.
├── index.html          # 入口
├── server.js           # 零依赖本地服务器
├── 启动游戏.bat        # Windows 一键启动
├── css/style.css       # 全部 UI 样式
├── js/
│   ├── core.js         # 工具 / 随机 / 噪声 / 输入 / 音效 / 存档封装
│   ├── data.js         # 元素 / 26 灵物 / 40+ 技能 / 道具 / 26 装备 / 6 地图 / 16 委托 / 成就
│   ├── sprites.js      # 程序化像素美术（体型原型 + 特征件 + 统一描边 + 色阶）
│   ├── world.js        # 地图生成（噪声 / 元胞自动机）、MST 连通、烘焙渲染、BFS 寻路
│   ├── entities.js     # 玩家 / 灵宠 / 魔物（含 BOSS 三阶段）/ 弹道 / 捕捉索 / 特效 / 掉落
│   ├── battle.js       # 伤害管线 / 技能释放 / 元素连携 / 捕捉 / 进化 / 掉落
│   ├── ui.js           # HUD 与全部面板 / 对话 / 商店 / 铁匠 / 标题 / 结局
│   └── game.js         # 主循环（含后台标签页兜底）/ 刷怪 / 事件 / 委托 / 存读档
├── docs/shots/         # 实机截图（含专家审查前后对照）
├── tools/verify.js     # 收工必跑：四套测试全绿
└── test/
    ├── harness.js      # 无头测试基础设施（DOM/Canvas 桩）
    ├── datacheck.js    # 数据自检（975 项）：引用完整性 / 排他性 / 获取路径
    ├── world.js        # 世界生成（83 项）：连通性 / 寻路 / 稳定性
    ├── smoke.js        # 全流程回归（102 项）：开局→战斗→捕捉→进化→委托→商店→BOSS→存档
    └── balance.js      # 数值体检（79 项）：TTK / 承伤 / BOSS 血量 / 捕捉期望 / 经济 / 升级节奏
```

## 开发者

```powershell
node tools/verify.js     # 四套测试全绿（1239 项断言）
node server.js [端口]    # 启动本地服务器（默认 8791）
```

- 主循环在 rAF 挂起时（后台标签页 / 被挂起的 webview）有 setInterval 兜底
- 存档：localStorage + 系统页导出/导入（导入时自动清洗非法装备/灵物引用）
- 改数值前先跑 `test/balance.js`；改数据后先跑 `test/datacheck.js`
